# bits to bits

Sculpt forms with your hands through the camera. Forms you keep join a collection, find their relatives and attach to them.

```bash
npm install
npm run dev
```

Open http://localhost:5173 in Chrome. Without a camera, choose "Use mouse instead".

Docs live in [docs/](docs): [plan](docs/PLAN.md), [design system](docs/DESIGN.md), [decisions](docs/DECISIONS.md).
